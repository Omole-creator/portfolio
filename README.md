# Omole Usuangbon — Portfolio

Personal portfolio for Omole Usuangbon, founder and growth operator. It tells one
story: someone who takes products from zero to paying customers, and builds the
tools that run the business.

## Tech

- Next.js (App Router) and TypeScript
- Tailwind CSS
- Framer Motion for scroll reveals and micro-interactions
- Lucide icons
- Playwright for end-to-end checks

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run test:e2e` — run the Playwright checks

## Notes

All copy and case-study data live in `lib/content.ts`, so wording and links are
easy to update in one place. Product screenshots have sensitive figures redacted
before they are used.
